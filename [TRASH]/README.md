# [TRASH] — Transparency Archive

This folder contains abandoned approaches, failed experiments, superseded scripts, and earlier pipeline iterations that were replaced during development.

Nothing here is used in the final dataset. It's kept for transparency — showing the real process, including the dead ends.

## What's in here

- **Early pipeline attempts** — extraction scripts that were rewritten or replaced
- **Superseded phases** — older versions of pipeline steps before restructuring
- **Failed approaches** — code that didn't work out (JS rendering issues, parsing failures, etc.)
- **One-off scripts** — utilities used once during debugging or exploration

## Why keep it

Every dataset project has false starts. Keeping them visible means anyone auditing this work can see the full journey — not just the polished result.
